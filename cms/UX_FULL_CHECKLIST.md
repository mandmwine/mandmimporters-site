# Small UX Features: The Complete Checklist

Oct 6, 2026 · @Rafael Mann

## 1. Search

- Search box visible on every list
- Global search across everything, reachable from any page
- Results update as you type, with a short pause so it does not flicker
- Enter also works for people who press it
- Placeholder says what is searchable: Search name, phone or order number
- Searches several fields at once (name, email, phone, notes, ID)
- Option to pick which field to search
- Ignores capital letters
- Ignores accents, punctuation and extra spaces
- Tolerates typos
- Matches partial words and the middle of words
- Matches phone numbers no matter how they are formatted
- Exact phrase search with quotes
- Exclude a word
- Nicknames and synonyms (Bob finds Robert)
- Matching text highlighted in results
- Result count shown
- Shows why a result matched when the match is in a hidden field (matched in notes)
- Clear button (x) inside the box
- Escape clears the box
- Keyboard shortcut jumps to search (slash or Ctrl K)
- Cursor starts in the search box on pages where searching is the main job
- Suggestions dropdown while typing
- Arrow keys move through suggestions, Enter opens
- Recent searches
- Suggested or popular searches
- Saved searches
- Results grouped by type (customers, orders, items)
- Results sorted by relevance
- Search inside current filters, or across everything, with a toggle
- Include archived toggle
- Search by ID, barcode or scan
- Voice search on mobile
- Search inside long dropdowns, menus and the settings page
- Find within a long document or page
- Spinner while searching
- Search term stays filled in when you come back from a record
- Search term kept in the URL
- Did you mean suggestions
- No results message with next steps: check spelling, clear filters
- Create new from the search term when nothing is found

## 2. Filtering

- Filter by any field
- One click status tabs (All, Open, Closed)
- Counts on each tab and each filter option
- Several filters combined
- Several values inside one filter (status is Open or Pending)
- Choice of match all or match any
- Exclude filter (is not)
- Text filters: contains, starts with, equals, is empty
- Number filters: more than, less than, between
- Range slider with typed values (price, party size)
- Date presets: today, yesterday, this week, last 7 days, this month, last month, this year
- Custom date range
- Relative dates that stay current (last 30 days)
- Yes or no toggles (only show unpaid)
- Mine or everyone toggle
- Filter by person, owner or location
- Filter by tag or category
- Filter by missing values (no phone number)
- Has attachment, has notes
- Created by me, changed recently
- Needs attention quick filter
- Include archived toggle
- Active filters shown as chips
- Remove one filter with its x
- Clear all filters
- Badge on the Filter button showing how many are active
- Obvious sign the list is filtered: Showing 12 of 340
- Filters apply instantly, or an Apply button on slow lists
- Search inside long filter lists
- Select all and clear inside a filter list
- Most used values listed first
- Options with zero results greyed out or hidden
- Click a value in the table to filter by it
- Filter from the column header
- Saved filters with names
- Set one saved view as the default
- Share a saved view with the team
- Pin favorite views as tabs
- Filters remembered when you return
- Filters kept in the URL so a link opens the exact view
- Reset to default
- Collapsible filter panel
- On mobile, filters open in a sheet with a Show 42 results button
- Empty result offers to clear filters

## 3. Sorting and ordering

- Click a column header to sort
- Click again to reverse, third click clears
- Arrow shows which column is sorted and which direction
- Sort dropdown for card views (Newest, Oldest, A to Z, Price low to high)
- Sort by more than one column
- Sensible default (usually newest first)
- Last sort remembered
- Sort kept in the URL and in saved views
- Sort applies to the whole list, not only the current page
- Numbers sort naturally (Table 2 before Table 10)
- Dates sort as dates, not as text
- Ignores capital letters and a leading The
- Empty values always go last
- Statuses sort in logical order, not alphabetical
- Sort by relevance while searching
- Sort by most used or recently used
- Sort by distance
- Sort inside groups
- Manual order by drag and drop
- Visible drag handle
- Move up, move down, move to top, move to bottom buttons
- Reorder with the keyboard
- Pin to top
- Rows do not jump while you are editing them
- Shuffle
- Reset to default order
